# Contributing

Thanks for considering a contribution.

## Bug reports

When opening an issue, include:
- Chrome version and operating system;
- extension version;
- what you expected and what happened;
- the exact visible error text, if any;
- steps to reproduce, without private account details.

Do **not** attach cookies, authorization headers, access tokens, raw HAR files, or screenshots containing personal information.

## Code changes

- Keep the extension limited to `https://flow.google.com/*`.
- Do not add remote code execution, telemetry, credential collection, or unrelated host permissions.
- Explain changes to RPC parsing and include tests or reproducible evidence where practical.
- Update `CHANGELOG.md` for user-visible changes.

## Pull requests

Keep pull requests focused and describe the behavior change, testing performed, and any remaining limitations.
